# Auto-helm 제품 요구사항 문서 (PRD)

> 상태: 초안 · 2026-10-25
>
> 이 문서는 사용자가 얻어야 할 결과와 제품의 동작을 정의한다.

## 1. 제품 개요

Auto-helm은 개인 투자자를 위한 한국 주식 분석·자동매매 제품이다. 관심 종목의 시세, 뉴스, 공시와 계좌 상태를 함께 살펴 매수·매도·대기를 판단하고, 그 이유와 실제 거래 결과를 기록한다. 사용자는 먼저 모의투자로 전략을 검증한 뒤 실전 거래를 활성화할 수 있다.

대상 사용자는 **한국투자증권 계좌로 KRX·NXT 주식을 거래하는 개인 투자자 1명**이다.

## 2. 제품 목표와 성과 지표

**제품 목표는 주식투자를 통한 순수익 창출 하나다.**

| 지표 | 정의 |
| --- | --- |
| 핵심 지표: 순수익 | 평가 기간의 실현·미실현 손익에서 수수료, 세금, 실제 체결 비용과 제품 운영 비용을 차감한다. 입출금은 투자 성과로 계산하지 않는다. |
| 순수익률 | 순수익을 투입 자본과 비교해 기간별로 측정한다. |
| 비교 지표 | 같은 기간의 단순 기준 전략과 순수익률을 비교해 전략의 기여를 확인한다. |
| 위험 지표 | 최대 낙폭, 일별 손실, 종목별 손실을 함께 표시한다. |

과거 데이터와 모의투자 결과는 실전 거래를 시작할지 판단하는 근거다. 목표 달성 여부는 실제 거래 결과로 평가한다. 평가 기간, 최소 거래 표본, 허용 손실, 주문 한도는 실전 거래를 활성화하기 전에 수치로 확정한다.

## 3. 핵심 사용 경험

1. **관찰:** 사용자는 관심 종목의 최신 가격, 거래 시장, 뉴스·공시, 가격 예측과 데이터 갱신 시각을 확인한다.
2. **이해:** 제품이 매수·매도·대기를 제안할 때 사용자는 판단 이유, 예상 거래비용, 위험 검사 결과를 확인한다.
3. **검증:** 사용자는 과거 판단과 당시 사용된 정보, 이후 가격 변화 및 거래 결과를 다시 살펴본다.
4. **거래:** 사용자는 모의거래에서 동작을 검증한 후 실전 자동매매를 켜고, 언제든 신규 주문을 중지할 수 있다.
5. **모니터링:** 사용자는 안드로이드 앱에서 거래·계좌·제품 상태를 조회하고 정보가 오래됐는지 알 수 있다.

## 4. 기능 요구사항

| ID | 단계 | 요구사항 | 완료 기준 |
| --- | --- | --- | --- |
| FR-01 | 기본 | 사용자는 관심 종목을 추가·제거하고 KRX·NXT 거래 가능 상태를 확인할 수 있다. | 거래가 불가능한 시장이나 종목에는 신규 주문이 제안되지 않는다. |
| FR-02 | 기본 | 제품은 관심 종목의 가격과 거래량을 실시간으로 반영하고 1분 단위 변화를 제공한다. | 각 가격에 시장과 시각을 표시한다. 수신이 끊기거나 값이 오래되면 지연 상태를 표시한다. |
| FR-03 | 분석 | 제품은 관심 종목과 관련된 새 뉴스·공시를 중복 없이 보여주고 AI가 사건의 성격과 종목 관련성을 분석한다. | 원문 출처, 발견 시각, 분석 완료 시각과 분석 상태를 확인할 수 있다. 정정 공시는 원 공시와 연결된다. |
| FR-04 | 분석 | 제품은 다음 1분, 1시간 뒤, 당일 KRX 공식 종가, NXT 거래 종료 기준 가격을 각각 예측한다. | 예측마다 기준 시각, 목표 시각, 사용 가능 여부와 실제 결과를 확인할 수 있다. 거래가 없는 목표는 유효한 예측처럼 표시하지 않는다. |
| FR-05 | 판단 | 제품은 이용 가능한 시세·예측·뉴스·공시·계좌 정보를 바탕으로 매수·매도·대기를 판단한다. | 판단의 입력과 이유, 예상 거래비용, 위험 검사 결과를 확인할 수 있다. 당시 아직 분석되지 않은 정보는 사용하지 않는다. |
| FR-06 | 판단 | 사용자는 판단 이력을 찾아보고 당시의 입력과 이후 결과를 비교할 수 있다. | 모든 확정된 판단에 종목, 시장, 시각, 사용한 정보, 결과와 정책 버전이 연결된다. |
| FR-07 | 거래 | 제품은 한국투자증권 모의투자 계좌에서 주문·정정·취소와 체결 상태를 처리한다. | 주문 제안과 실제 접수·거부·부분 체결·체결·취소를 구분해 보여주고 증권사 내역과 일치시킨다. |
| FR-08 | 거래 | 제품은 검증된 전략에 한해 실전 계좌의 자동매매를 지원한다. | 모의투자와 실전투자의 계좌·거래 내역이 구분되고, 실전 기능은 별도 활성화 전까지 주문하지 않는다. |
| FR-09 | 거래 | 사용자는 종목별·일별 주문 금액과 손실 한도를 설정하고 신규 주문을 즉시 중지할 수 있다. | 한도 초과나 중지 상태에서는 신규 주문이 접수되지 않는다. 중지 상태가 사용자에게 표시된다. |
| FR-10 | 거래 | 제품은 데이터 누락, 오래된 시세·계좌 정보, 불확실한 주문 결과가 있을 때 신규 진입을 보류한다. | 오류 상황에서 중복 주문이 발생하지 않는다. 거래 재개 전 증권사 주문·체결·잔고와 상태가 대조된다. |
| FR-11 | 성과 | 사용자는 모의·실전 성과를 거래비용 반영 순수익, 순수익률, 손실 규모와 기준 전략 대비 결과로 볼 수 있다. | 기간과 환경을 선택해 성과를 조회할 수 있고, 각 수치는 주문·체결 내역으로 검산할 수 있다. |
| FR-12 | 모니터링 | 안드로이드 앱은 관심 종목, 계좌, 판단, 주문 및 제품 상태를 조회 전용으로 보여준다. | 모의·실전 상태를 명확히 구분하고 마지막 갱신 시각을 표시한다. 앱에서 주문하거나 전략을 바꿀 수 없다. |

## 5. 제품 동작 원칙

- AI 분석 결과는 판단의 입력이다. 실제 주문은 거래 가능 여부, 계좌 상태, 주문 한도와 위험 조건을 모두 충족할 때만 실행한다.
- KRX와 NXT는 거래 시간과 종료 가격이 다르다. 제품은 시장별 거래 가능 여부와 가격 목표를 구분한다.
- 매매 판단에는 **그 시점에 제품이 실제로 확보한 정보**만 사용한다. 늦게 도착한 뉴스·공시 분석으로 과거 판단을 바꾸지 않는다.
- 정보가 불완전하거나 충돌하면 신규 진입의 기본 동작은 대기다. 보유 포지션의 위험 대응은 별도 조건에 따른다.
- 주문 응답이 불확실하면 같은 주문을 즉시 반복하지 않는다. 증권사 내역과 대조해 상태가 확인될 때까지 신규 주문을 중지한다.
- 예측과 모의투자 성과는 실전 수익을 보장하는 신호로 표시하지 않는다.

## 6. 출시 단계와 실전 활성화 조건

| 단계 | 사용자가 할 수 있는 일 |
| --- | --- |
| 1 · 관찰과 기록 | 시세·뉴스·공시·계좌 상태와 데이터 갱신 시각을 확인하고 판단 이력을 쌓는다. 주문은 실행하지 않는다. |
| 2 · 분석과 모의투자 | 가격 예측과 AI 분석을 확인하고 모의계좌에서 자동매매 및 성과를 검증한다. |
| 3 · 실전 거래 | 사전에 정한 성과·손실·안정성 기준을 충족한 버전으로 실전 자동매매를 시작한다. |
| 4 · 원격 모니터링 | 안드로이드 앱에서 모의·실전 상태를 읽기 전용으로 확인한다. 이 단계는 실전 거래 전에도 제공할 수 있다. |

실전 거래를 활성화하려면 다음을 모두 확인한다.

1. 과거 기간과 모의투자에서 거래비용을 반영한 성과를 측정했고, 사전에 정한 평가 기간·표본·허용 손실 기준을 충족한다.
2. 주문 접수 실패, 응답 지연, 부분 체결, 통신 장애와 재시작 상황에서 중복 주문 없이 상태를 복구한다.
3. 모의계좌와 실전계좌가 구분되며, 사용자가 실전 주문 한도와 중지 상태를 확인할 수 있다.
4. 실전 첫 가동은 제한된 주문 한도로 시작하고 실제 주문·체결 내역을 증권사와 대조한다.

## 7. 제외 범위와 확정할 기준

**초기 범위에서 제외:** 타인 계좌 관리, 다중 사용자 서비스, 해외 주식·파생상품, 모바일 주문, AI 분석 결과의 무조건적인 주문 실행.

**실전 활성화 전 확정:** 관심 종목 범위, 성과 평가 기간과 기준 전략, 최소 표본, 주문·손실 한도, 허용 가능한 데이터 지연, 모의투자에서 지원되는 KRX·NXT 주문 범위.
